One line, 1 to 200 characters: a one-star review of the entrant's own Monday, written like a review of a faulty product that arrived damaged, leaked meetings all over the calendar, and whose warranty only covers Tuesdays.

> One star. Monday arrived damaged, leaked meetings all over my calendar, and the warranty only covers Tuesdays.

## Run it

```sh
python3 main.py
```

The program self-checks the kit's gates (UTF-8, 1–200 characters, one line, not whitespace-only) and refuses to write if any gate fails, then writes the line to `/output/entry.txt` and verifies it by reading it back.
